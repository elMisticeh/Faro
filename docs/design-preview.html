Opciones de logo

A — Wordmark
Solo tipografía. Limpio, directo. El nombre hace todo el trabajo.
B — Pin
Círculo con núcleo + wordmark. Evoca un pin de mapa o punto de datos.
C — Signal
3 barras de señal ascendente. Analytics, datos, crecimiento. Muy reconocible.
D — Vector
Línea diagonal + punto origen. Evoca dirección, tendencia, trayectoria de mercado.
E — Frame
Corchetes [ ]. Enmarca los datos. Código, precisión, análisis. Muy tech.
F — Slash
Diagonal + punto final. Minimal extremo. Funciona en 16px y en valla publicitaria.
